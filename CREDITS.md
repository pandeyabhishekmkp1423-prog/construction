## 2. Typography Rationale
The site utilizes a carefully ordered system typeface stack designed for engineering precision:
- **Display / Headings:** `"DIN Alternate", "Franklin Gothic Medium", "Arial Narrow", -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif` — Provides a sturdy, condensed architectural grotesque appearance typical of engineering documentation and structural drawings.
- **Body Text:** `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif` — Delivers clean, highly readable humanist legibility across all desktop and mobile viewports.
- **Technical Notation:** `ui-monospace, SFMono-Regular, "SF Mono", Menlo, Consolas, monospace` — Applied to section numbering, coordinates, and drawing metadata.
- **Performance & Privacy:** Zero external web fonts (no Google Fonts or third-party CDNs), ensuring 0 render-blocking network requests, 0 Cumulative Layout Shift (CLS), and 100% GDPR data privacy compliance.

## 3. Libraries & Frameworks
- Zero external CSS or JavaScript frameworks (no Bootstrap, Tailwind, jQuery, or React).
- All CSS and vanilla JavaScript scripts are 100% custom, lightweight, and self-hosted.
